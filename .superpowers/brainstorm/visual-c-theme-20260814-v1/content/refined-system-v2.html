实施强度怎么选？

我建议选择 A：把参考站的视觉纪律系统化，而不是让每个业务页面都变成作品集。

A

平衡型全站升级 推荐

三套完整主题 + 新字体系统 + Motion 页面过渡 + 少量 Canvas/CSS 氛围动效。

  • 登录、首页强视觉
  • 业务工作区克制可读
  • 性能与维护成本可控
B

全站强动效实验化

刷题、学习、报告等页面也使用持续粒子、滚动场景与大幅构图。

  • 冲击力最强
  • 内容页干扰更高
  • 移动端与性能风险最大
C

分阶段逐页升级

先优化登录、首页、刷题入口，再扩展学习、面试、成长和设置页面。

  • 回归风险最低
  • 每阶段可独立验收
  • 短期内页面风格会新旧并存
