# 结构化客观题与 Agent 题库扩充设计

## 目标

在不破坏现有开放题练习流程的前提下，为题库增加真正可交互的单选题和多选题，并补充一批覆盖 AI Agent 工程核心知识的公开题目。

## 范围

- 新增 `single_choice`、`multiple_choice` 两种题型。
- 题目可携带 2 至 8 个结构化选项和正确选项 ID。
- 单选题必须且只能有一个正确选项；多选题至少有两个正确选项；正确选项必须来自题目选项。
- 目录与练习会话返回选项，但不返回正确选项 ID。
- 练习页使用 radio/checkbox 作答，答案分别按 `A` 和 `A,C` 的稳定格式保存。
- 新增 12 道单选题、8 道多选题、12 道开放题，覆盖 LLM、Prompt、RAG、工具调用、MCP、Agent 架构、多 Agent、记忆、评估、可观测性、安全、可靠性与推理优化。
- 参考资料仅用于 taxonomy、知识核验和题型设计；新题重新组织表述并保留来源链接。

## 架构与数据流

共享契约新增 `QuestionOption`，并在完整题目上校验题型、选项和答案之间的条件约束。Prisma 的 `Question` 与 `CandidateQuestion` 增加 `options` JSON 和 `correctOptionIds` 字符串数组；旧题使用空数组，保持兼容。

题库目录通过公开题目摘要返回 `options`，显式排除 `answer`、`rubric` 和 `correctOptionIds`。练习会话同样只返回选项。用户端将选择序列化到现有字符串答案字段，服务端评价输入增加选项文本，确保 AI 能理解 `A,C` 所代表的内容。

## UI 行为

- 单选题展示 radio 列表，切换选项会替换当前答案。
- 多选题展示 checkbox 列表，答案按题目选项顺序排序，避免等价答案产生不同草稿字符串。
- 未选择选项时不能保存；保存、下一题、草稿恢复和反馈入口沿用现有状态机。
- 开放题仍展示 textarea，不改变已有交互。

## 边界

- 本次不增加独立考试模式、倒计时、客观题统计报表或无需 AI 的即时自动评分。
- 后台候选题模型具备存储选项的能力，但本次不新增复杂的可视化选项编辑器。
- 不复制外部仓库整段题目或答案；涉及 CC BY-SA 的资料只作为分类参考并保留许可说明。

## 验证

- 契约测试覆盖合法/非法单选和多选，以及正确答案不泄漏。
- 题库测试覆盖新增数量、题型分布、ID 唯一性和共享契约校验。
- 用户端测试覆盖 radio/checkbox 渲染、选择序列化和开放题回归。
- Product API 测试覆盖目录选项返回、题型标签和评价 prompt 中的选项。
- 运行 Prisma validate/generate、定向测试、类型检查、lint 和 build。
