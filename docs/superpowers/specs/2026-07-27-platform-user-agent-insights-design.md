# 平台用户与 Agent 使用洞察设计

## 目标

在平台数据看板的同一时间窗口内，补充可用于运营判断的用户参与和四类业务 Agent 使用情况；所有数字来自既有业务记录，不保存或展示对话内容。

## 设计

数据看板在“经营趋势 / 运行质量”之后增加一个双列洞察区：

- **用户使用情况**：展示窗口内登录的普通用户、模拟面试次数、练习提交次数和已生成报告数，并用从“活跃用户”到“报告产出”的紧凑链路说明参与深度。
- **Agent 使用情况**：固定展示模拟面试、练习评估、用户助手和管理员助手。每项展示调用次数、成功次数和成功率；零调用保持可读的 `0%` 状态。

继续使用 `GET /admin/platform/dashboard?period=today|7d|30d`。接口新增 `userUsage` 与 `agentUsage` 字段：前者由普通用户登录及既有训练数据组成，后者从 `AiInvocation` 以四个业务 operation 聚合；模型连接测试不属于 Agent，因此不包含在该区块。

## 边界与验证

- 不修改 Prisma schema、迁移、模型调用日志内容、权限或路由。
- 复用 `analytics:read` 平台权限和现有周期切换。
- 共享契约、后端聚合和前端渲染均补测试；运行 contracts、Product API 定向 Jest 和 Admin Console Vitest，并检查格式与类型构建。
