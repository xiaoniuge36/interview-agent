# 首页训练计划设计

## 目标

将用户首页重构为“今天可以马上开始的一轮训练计划”：Agent 推荐占据首屏主位，用户可继续未完成练习、查看最近训练，或进入题库自主选择。首页不再与题库页争夺“发现题目”的职责，而是负责帮用户决定下一步。

## 范围与约束

- 只修改用户端首页、首页推荐组件与局部样式、静态测试。
- 不修改推荐算法、请求、合同、题单创建、评分、持久化、路由、认证、主题存储或依赖。
- 使用现有 dawn、ocean、night 主题以及 coral、blue、teal、amber 强调色；不得在首页局部样式中写死十六进制颜色。
- 推荐题单的开始操作继续调用现有 `onStart(recommendation)`；最近练习继续沿用现有链接。
- 推荐加载、无推荐、失败和创建题单失败均提供清晰说明及可执行的自主选题降级路径。

## 视觉方向：今日训练计划

首页是一张“训练开场卡”，不是展示性仪表盘。用户首先看到 Agent 为什么建议当前题单、训练规模和开始按钮；随后看到继续上次练习和自选题库。题库主题分类从首页主内容降为快速发现，服务于自主选择而不是分散主操作。

```text
今天的训练计划
推荐理由 · 题目数 · 时长
[采用并开始训练]  [自己组一轮]

继续上次练习（仅有未完成记录时）
快速发现：能力主题与题库入口
```

### 签名元素：训练意图卡

训练意图卡使用实际推荐的来源、理由、题数和时长，表达“为什么现在练这一轮”。它与题库页的推荐卡共享主题语义，但在首页以宽卡形式呈现，避免两处视觉语言分裂。

## 页面状态

| 状态       | 主区内容                             | 降级操作         |
| ---------- | ------------------------------------ | ---------------- |
| 推荐加载中 | 正在读取训练线索，保留训练入口       | 自己组一轮       |
| 有推荐     | 推荐题单、依据、题数、时长与开始按钮 | 自己组一轮       |
| 无推荐     | 暂无优先补强项                       | 进入题库自主组卷 |
| 推荐失败   | 推荐暂不可用，不影响训练             | 重试；自己组一轮 |

## 交互与响应式

- 所有推荐状态均保留“自己组一轮”作为可见行动，不把训练入口藏入侧栏。
- 移动端按“推荐计划 → 最近练习 → 快速发现”单栏堆叠；主操作与自选入口占满可用宽度。
- 保留已有短过渡；减少动画偏好下停用呼吸、扫描与位移动效。
- 推荐状态、题单创建错误与最近练习进度通过文本说明，不能只依赖颜色和进度条。

## 验收标准

1. 首页首屏展示推荐计划和开始操作；自主选题始终可见。
2. 最近练习只在存在实际未完成记录时展示，继续链接和进度含义保持不变。
3. 无推荐和失败不阻塞训练，用户可直接进入自主选题。
4. 首页局部颜色全部从主题 token 派生，相关测试、typecheck、lint、生产构建通过。
