# 后台管理体验打磨设计

## 目标

在不调整后台 API、权限模型、数据结构或导航路由的前提下，吸收 `create-admin-platform` 的可发现性、个性化与运营可见性细节，提升管理员处理日常工作的效率。

## 范围

### 运营效率

- 在顶部提供 `Ctrl/⌘ K` 快捷命令面板，按当前角色只展示可访问模块。
- 将已访问模块记录为最近访问，支持收藏当前模块；两者保存在浏览器本地。
- 在侧栏和总览显示“我的工作台”，以现有 hash 导航进入模块。

### 个性化

- 提供浅色/深色外观与紧凑/舒适密度的切换菜单。
- 将外观、密度、收藏与最近访问与既有侧栏折叠状态一样保存在 `localStorage`。
- Ant Design token 与自定义 CSS token 同步响应外观，避免组件与页面底色不一致。

### 治理可见性

- 在总览增加由既有 Dashboard 数据计算的“需处理事项”。
- 待审核候选题、失败导入、失败或降级的 Agent 运行、低于 100% 的 Schema 通过率均显示为可跳转事项。
- 数据尚未加载时不渲染推测性状态；无事项时明确显示队列正常。

## 数据与权限

- 所有个人偏好仅存储在当前浏览器，不上传 Product API。
- 命令面板、收藏和最近访问都使用既有 `canAccessAdminView` 过滤，角色变更后不会暴露未授权入口。
- 可见性事项只使用 `/admin/dashboard` 已返回的统计和近期运行数据。

## 验证

- 为纯工作台状态函数补充 Vitest 单测，覆盖最近访问去重/截断、收藏切换与非法持久化值过滤。
- 执行后台包的 test、typecheck、lint、build。
