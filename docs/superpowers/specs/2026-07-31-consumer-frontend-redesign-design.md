# C 端行动首页与消费级体验改造设计

## 目标

将 `apps/user-portal` 从“带侧栏的功能工作台”改造成面向求职者的消费级学习与面试产品。首屏回答三个问题：今天该做什么、为什么做、完成后离目标更近多少。保留现有认证、题库、学习、面试、报告和 Agent 数据流，不调整 API、schema 或业务状态机。

## 参考结论

- iFace 的可取之处是轻量顶栏、清晰题库入口、低摩擦刷题和可见进度；不复制其题目或实现。
- Stitch 用户端设计的信息层级清楚，但固定侧栏、工具栏和大量面板仍偏企业工作台，不作为 C 端外壳。
- Huru、Final Round AI 等产品把“目标岗位 -> 模拟训练 -> 即时反馈 -> 再练”组织成连续旅程，而不是平铺模块。
- 学习产品案例强调当前课程、继续学习、进度和移动端可达性；分析数据只服务下一步，不占据首屏中心。

## 已确认方向

采用 A「行动首页」。产品主题为“求职者每天打开就能开始一次有依据的训练”，受众是准备 AI 应用、前端与全栈岗位的中文求职者，页面的单一任务是让用户在十秒内开始或继续最值得做的一步。

## 信息架构

1. 桌面端采用轻量顶栏：首页、刷题、学习、模拟面试、成长；低频设置收进账号区。
2. 移动端保留底部导航，但减轻深色悬浮工具栏感，改成明亮、原生应用式标签栏。
3. 首页按“问候与目标 -> 今日下一步 -> 本周进度 -> 自由探索题库”组织。
4. 学习中心按“路线总览 -> 当前课程 -> 阅读正文 -> 本页目录”组织，课程列表是学习路径，不是后台菜单。
5. 登录页展示用户登录后将继续的真实训练场景，不再以功能清单说服用户。

## 视觉系统

- `Paper`：`#f7f5f1`，用于长时间阅读背景。
- `Ink`：`#24242d`，用于标题与正文主信息。
- `Coral`：`#df5c3b`，仅用于主行动与当前状态。
- `Violet`：`#6258ea`，用于学习路径与 AI 辅助信息。
- `Moss`：`#168676`，用于完成、连续学习和正向证据。
- 标题使用现有 Plus Jakarta Sans 与中文系统字体组合；正文保持高可读中文字体栈。
- 大容器圆角 18–24px，内容卡片 12–16px，交互按钮使用胶囊形；弱化边框和阴影。
- 标志性元素是首页“今日下一步”深色任务卡：用一处克制的轨道圆弧暗示训练路径，其余页面保持安静。

## 动效组件吸收

- 参考 React Bits Split Text，为首页行动标题提供字符级错峰入场；中文按 Unicode 字符拆分，完整文本保留为无障碍名称，减少动态时立即静态显示。
- 参考 Aceternity Evervault Card，把通用“加密字符”改写为 Agent 工程信号场：`AI`、`RAG`、`{}`、`01` 与箭头构成低对比纹理，只用于今日任务卡的悬停层，不遮挡正文。
- 参考 Uiverse 按钮库的 CSS 微交互，为主操作提供箭头推进、按压位移与 busy 状态；不引入第三方依赖，也不在次要按钮上重复使用。
- 三类动效均以当前产品语义重新实现，不复制示例源码，不改变按钮、链接和标题的原生语义。

## 页面设计

### 登录页

左侧改为明亮的教练预览：一句直接价值主张、一张今日任务卡和连续训练提示。右侧表单取消大面积后台卡片感，使用更窄的内容列、清晰标签与单一主按钮。移动端先表单后价值提示，避免首屏被宣传内容占满。

### 全局外壳

固定侧栏改为粘性顶栏。品牌、主要导航、搜索与账号操作处于同一视觉层级。页面内容统一置于最大宽度容器中；工作空间类页面仍可自行突破宽度。全局搜索保留 `Ctrl K` 和对话框能力，但入口收敛为顶栏搜索胶囊。

### 首页

Agent 推荐或未完成训练成为唯一主任务卡。推荐理由保留但降为一句证据；自由组题作为次要链接。本周训练、学习路线与题库专题位于下方，避免同级大卡片争抢注意力。

### 学习中心

路线总览成为横向/左侧课程轨道，正文保持 680–760px 阅读宽度，目录为安静的辅助导航。完成状态用绿色勾选，当前课用珊瑚色标识。移动端课程轨道横向滚动，正文单列。

## 响应式与可访问性

- 1180px 以下收紧顶栏并允许导航横向滚动。
- 820px 以下隐藏桌面顶栏导航，使用底部导航；内容变为单列。
- 480px 以下登录表单优先显示，任务卡和题库卡减少装饰。
- 保留语义导航、`aria-current`、加载状态、键盘焦点和 `prefers-reduced-motion` 支持。

## 验证

- 运行 user-portal 的 Vitest、ESLint、TypeScript 与 Next.js build。
- 在桌面和移动视口检查登录页、首页与学习中心截图。
- 核对认证、导航 pending、推荐开始、继续训练、课程进度和搜索入口没有行为回归。
