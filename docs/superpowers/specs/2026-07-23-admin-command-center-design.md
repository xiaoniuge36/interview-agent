# 后台统一命令中心设计

## 目标

将后台顶部重复的“快捷”按钮和“搜索功能 / 模块”输入框合并为一个统一命令入口，并补齐键盘导航与抽屉开启时的紧凑布局。管理员应能在不离开键盘的情况下完成模块查找和跳转，同时不改变现有权限、路由或本地偏好数据。

## 设计决策

### 单一入口

- 顶部只保留一个“搜索模块或命令”触发器，展示搜索图标和 `Ctrl K` 提示。
- `Ctrl/Cmd + K` 或点击触发器打开命令面板。
- 删除独立的 `AutoComplete` 搜索框，避免两个入口表达同一能力。

### 键盘优先

- 面板打开后自动聚焦搜索框。
- `ArrowDown` / `ArrowUp` 循环移动当前选项，`Enter` 执行，`Escape` 关闭。
- 鼠标悬停同步当前选项，点击行为与键盘执行一致。
- 搜索输入和结果列表通过 `aria-controls`、`aria-activedescendant`、`role=listbox/option` 关联。

### 结果组织

- 无搜索词时依次展示收藏、最近访问和全部模块。
- 同一模块只在最高优先级分组出现一次：收藏优先于最近访问，最近访问优先于全部模块。
- 有搜索词时只展示一个“搜索结果”分组。
- 所有结果继续使用 `canAccessAdminView` 过滤，角色变化不会暴露无权限入口。

### 响应式行为

- 正常桌面宽度展示完整触发器。
- 中等宽度隐藏快捷键提示，窄屏隐藏文字，仅保留有无障碍名称的搜索图标。
- Agent 抽屉开启时，顶部进入紧凑态：为抽屉保留空间、收缩命令入口，并隐藏低优先级刷新摘要；抽屉关闭后恢复。
- 不修改 Agent 抽屉宽度、后台导航和页面内容布局。

## 边界

- 不修改 Product API、数据库、contracts、权限角色或 hash 路由。
- 不新增依赖。
- 不实现任意业务动作命令；命令中心本轮只负责现有后台模块跳转。
- 不改动用户已有的收藏和最近访问持久化格式。

## 验证

- 纯函数测试覆盖权限过滤、分组去重、上下循环选择和空结果。
- 组件静态测试确认顶部只保留一个命令入口。
- 运行 Admin Console test、typecheck、lint、build。
- 在真实后台验证普通桌面、Agent 抽屉打开和窄屏三种布局，以及 `Ctrl/Cmd + K`、方向键、Enter、Escape。
