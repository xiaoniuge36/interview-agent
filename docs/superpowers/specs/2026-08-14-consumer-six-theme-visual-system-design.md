# C 端六主题视觉系统与动效升级设计

## 目标

在不改变 `apps/user-portal` 现有页面信息架构、业务数据流、路由与核心交互逻辑的前提下，重做 C 端视觉语言和动效系统。解决当前页面存在的字体层级弱、主题差异只停留在换色、组件材质同质化、中文排版不稳定、页面状态缺少连贯反馈等问题。

最终交付六套可切换主题，统一中文界面文案和滚动字幕，并把动画用于页面进入、导航切换、任务反馈、滚动显现与少量环境氛围。管理端、后端 API、数据库、业务状态机和训练推荐算法不在本次范围内。

## 已确认的设计原则

1. 保留现有整体排版与页面功能分区，不以重新规划信息架构的方式制造视觉变化。
2. 六套主题是六种完整视觉语言，不共用同一套圆角卡片后只替换颜色。
3. 登录页与首页承担品牌记忆点；刷题、学习、面试、报告等长时使用页面优先保证可读性。
4. 所有用户可见导航、标签、状态提示、滚动字幕与训练文案使用中文；技术缩写仅在 RAG、MCP 等真实概念中保留。
5. 一套页面同时只有一个主动画焦点。环境动画保持低速，业务反馈保持短促，不让所有元素持续运动。
6. 主题切换、减少动态效果、键盘焦点、移动端和低性能设备均有明确降级路径。

## 参考方向

- ZCode Effects Gala：超大字号、章节叙事、粒子与滚动显现。
- ZCode Constructivist：粗重中文、红黑米白、硬边、斜切和印刷构图。
- ZCode Terminal/Aurora：等宽技术语义、细网格、渐变巨字和环境粒子。
- Apple Liquid Glass：空间材质、景深、连续形变与内容可读性边界。
- Duolingo Brand、Codecademy：高饱和模块、明确成长反馈与学习场景的即时正反馈。

这些参考只用于提炼设计纪律和交互规律，不复制页面源码、品牌素材或专有控件。

## 六套主题

| 主题 ID | 中文名称 | 核心色彩 | 字体与组件语言 | 标志性动效 |
| --- | --- | --- | --- | --- |
| `aurora` | 极光叙事 | 深黑、紫蓝、青色、洋红 | 渐变巨字、玻璃暗面板、轨道圆环 | 粒子漂移、轨道呼吸、柔光扫描 |
| `terminal` | 终端工业 | GitHub 深灰、蓝色、绿色 | 等宽标题、命令语义、细边框、方角 | 状态扫描、光标脉冲、命令逐段显现 |
| `constructivist` | 结构主义印刷 | 米白、墨黑、朱红 | 粗重中文、硬边、斜切、印章与厚投影 | 印章漂浮、几何旋转、块面切入 |
| `daylight` | 白昼编辑部 | 白色、墨黑、钴蓝、朱红 | 高对比网格、粗字、硬边白卡 | 标题错峰上浮、圆环运动、任务卡扫描 |
| `glass` | 雾光玻璃 | 冰蓝白、淡紫、薄荷青 | 半透明材质、空间层级、柔和圆角 | 折射高光、弹性形变、轻量视差 |
| `playground` | 彩色训练场 | 明亮黄绿、天蓝、紫色、珊瑚 | 高饱和模块、粗边、成长反馈 | 模块弹跳、能力值反馈、完成庆祝 |

`daylight` 作为新用户默认主题。它在明亮环境和长时间阅读中最稳妥，同时仍具有明确的品牌识别。六套主题都必须满足正文、输入框、按钮、禁用态和焦点态的对比度要求。

## 主题状态与兼容迁移

主题偏好升级为 `offerpilot:theme-preferences:v2`：

```ts
type ThemeMode =
  | 'aurora'
  | 'terminal'
  | 'constructivist'
  | 'daylight'
  | 'glass'
  | 'playground';

type ThemePreferences = {
  theme: ThemeMode;
  motion: boolean;
};
```

旧版 `v1` 偏好按以下规则迁移：

- `dawn` → `daylight`
- `ocean` → `glass`
- `night` → `aurora`
- 原 `accent` 仅作为旧数据兼容输入，不再单独暴露为任意配色开关。
- 原 `motion` 值完整保留。

取消独立主题色选择，是为了避免六套完整视觉语言与四种任意强调色组合成不可控的二十四种视觉结果。主题内部通过语义 token 管理主色、辅助色、成功、警告和危险状态。

无效或损坏的本地偏好回退到 `daylight + motion on`。根布局的同步启动脚本必须在首屏渲染前完成迁移与 `data-theme`、`data-motion` 设置，避免主题闪烁。

## 字体系统

当前项目只为拉丁字符加载 Plus Jakarta Sans，中文依赖系统回退，导致不同设备上的字重、字面大小和换行不稳定。本次统一为三层字体角色：

- `--font-display`：Noto Sans SC，700–900，用于首页主标题、任务标题、章节标题。
- `--font-body`：Noto Sans SC，400–700，用于表单、题目、课程、报告和说明文本。
- `--font-tech`：JetBrains Mono，600–800，用于真实技术缩写、计时、进度、编号与开发者语义标签。

字体沿用项目现有 `next/font` 自托管模式，不在浏览器运行时请求外部字体。中文主标题通过字号、字重、行高与字距建立表现力，不依赖难以部署或许可不清晰的展示字体。

## 语义设计 token

所有业务组件只消费语义变量，不直接写主题色：

```css
--theme-canvas;
--theme-surface;
--theme-surface-raised;
--theme-ink;
--theme-text-muted;
--theme-line;
--theme-primary;
--theme-secondary;
--theme-accent;
--theme-success;
--theme-warning;
--theme-danger;
--theme-shadow;
--theme-radius-panel;
--theme-radius-control;
```

主题可以改变圆角、阴影、边框厚度和材质。例如 `constructivist` 使用零圆角和硬投影，`glass` 使用半透明表面和柔和圆角，`terminal` 使用细边框与极小圆角。业务状态仍通过相同变量表达，不以颜色作为唯一信息来源。

## 动效架构

新增 `motion` 作为唯一 React 动效编排库，采用 `LazyMotion` 与 `domAnimation` 控制客户端体积。根 Provider 使用 `MotionConfig reducedMotion="user"`，并继续尊重产品内的 `motion` 开关。

### 通用动效原语

- `PageMotion`：路由内容淡入、轻微位移与退出，避免整页闪切。
- `StaggeredTitle`：中文按短语或行分组错峰进入，不逐字符制造噪声。
- `SharedNavIndicator`：导航当前项使用共享布局下划线平滑移动。
- `RevealSection`：课程、报告和设置分区进入视口时按阅读顺序显现。
- `ActionFeedback`：保存、开始训练、下一题、完成等高频动作使用短促弹性反馈。
- `ThemeTransitionLayer`：主题切换时对画布、表面和文字做 240–360ms 过渡，不对所有节点执行昂贵动画。
- `ThemeAtmosphere`：只在登录、首页和空状态中显示主题环境层。
- `ChineseTicker`：滚动内容全部中文；内容不足时复制队列形成无缝循环。

### 环境动画边界

- 粒子、光标、扫描、圆环和折射高光只允许出现在环境层或单一主任务卡。
- Canvas 仅用于 `aurora` 等确实需要粒子效果的登录与首页场景，最多一个画布实例。
- Canvas 动画限制帧率，页面隐藏、组件离开视口、关闭动态效果或匹配 `prefers-reduced-motion` 时暂停。
- 移动端降低粒子数量、模糊半径和视差幅度；低性能设备使用静态渐变或 CSS 背景替代。
- 内容密集页面不使用持续移动的背景，避免影响答题和阅读。

## 页面应用规则

### 登录页

- 保留登录与注册流程、验证、错误提示和认证模式。
- 左侧/背景使用当前主题的环境层和一条训练任务预览。
- 表单字段保持高对比，不在输入区叠加粒子、扫描或复杂玻璃。
- 首屏标题、任务预览和表单按一个短序列进入，认证请求期间不重复播放。

### 全局外壳

- 保留桌面顶栏、移动端底部导航、全局搜索、账户和设置入口。
- 主题选择器改为六张预览卡，桌面两列、移动端单列。
- 导航当前项、搜索触发器、账户区随主题改变材质，但不改变语义和键盘行为。

### 首页

- 保留问候、训练推荐、继续训练、搜索、题库专题和发现内容。
- 超大中文行动标题与今日主任务卡构成唯一视觉焦点。
- 中文滚动字幕使用真实训练概念，如“上下文工程、检索增强生成、工具调用、智能体记忆、面试证据、训练复盘”。
- 推荐依据、自主组题和失败重试保持可见，不以动画遮挡状态。

### 刷题与练习

- 入口页可使用主题标志性构图；答题播放器回归稳定、低干扰的工作区。
- 保存、保存并下一题、评分生成和完成反馈使用 `ActionFeedback`。
- 题目、选项、答案、解析与 Agent 反馈保持清晰文本层级，不使用持续粒子背景。

### 学习中心

- 路线、章节和正文使用主题字体、编号与分隔系统。
- 课程切换使用共享布局和滚动显现；正文阅读宽度不随主题变化。
- `constructivist` 和 `playground` 的高表现元素只用于章节头部，不进入正文段落背景。

### 模拟面试

- 会话开始前允许主题化环境层；会话进行中收敛为沉浸式工作区。
- 当前问题、回答编辑、运行状态、转写记录和报告状态优先。
- 不新增倒计时、总题数或后端未提供的能力指标。

### 成长、档案与设置

- 报告、错题、档案、岗位目标、模型设置复用统一分区、空态和错误态。
- 动画仅用于分区进入、筛选结果变化和状态确认。
- 密钥、模型连接与错误信息保持现有安全边界，不通过视觉重构改变数据提交逻辑。

### 全局搜索与用户 Agent

- 保留对话框、快捷键、抽屉、拖拽和会话恢复逻辑。
- 根据主题调整表面与焦点样式；对话列表变化使用轻量布局动画。
- 不在 Agent 对话正文中使用滚动字幕或环境粒子。

## 组件边界

预期新增或调整以下边界：

- `ThemePreferencesProvider`：v1 → v2 迁移、六主题类型、动态效果设置。
- `ThemeMenu`：六主题预览与中文说明。
- `WebProviders`：接入 Motion Provider。
- `PageMotion`、`StaggeredTitle`、`SharedNavIndicator`、`RevealSection`、`ActionFeedback`。
- `ThemeAtmosphere`、`ChineseTicker`。
- 主题 token 拆分为基础语义层和六个主题覆盖层。
- 页面组件只增加必要的动效包装和主题 class，不重写业务请求 Hook 或状态模型。

## 响应式与无障碍

- 1180px 以下收紧导航与主标题字号。
- 820px 以下隐藏桌面主导航，保留移动端底栏；主题预览改为单列。
- 480px 以下减少环境层装饰、关闭视差并让主行动占满可用宽度。
- 所有可点击元素保持可见焦点、键盘操作、语义标签和最小触控区域。
- `prefers-reduced-motion`、产品动态效果开关任一关闭时，持续动画停用，入场动画降级为即时显示或短淡入。
- 颜色对比、状态图标和文字说明共同表达成功、警告、危险和加载状态。

## 性能边界

- 仅引入 `motion`，不同时引入 GSAP、AutoAnimate 或整套动画组件库。
- React Bits 等在线案例仅作为交互灵感，组件使用项目 token 重新实现。
- 环境层按页面懒加载；非首页路由不加载 Canvas 代码。
- 避免在滚动事件中直接修改布局，优先使用 Intersection Observer、transform 与 opacity。
- 主题切换不触发业务数据重新请求或 Workspace Provider 重挂载。
- 浏览器端验证需检查动画开启、动画关闭、页面后台恢复和移动端降级。

## 测试与验收

### 自动化

- 主题偏好解析、v1 → v2 迁移、无效值回退。
- 六主题菜单渲染、键盘操作、动态效果开关。
- Motion Provider 的减少动态效果分支。
- 中文滚动字幕与无障碍文本。
- 登录、首页、练习入口、学习中心等已有组件测试保持通过。
- `pnpm --filter @interview-agent/user-portal test`
- `pnpm --filter @interview-agent/user-portal lint`
- `pnpm --filter @interview-agent/user-portal typecheck`
- `pnpm --filter @interview-agent/user-portal build`

### 视觉检查

- 桌面 1440×1000：登录、首页、刷题入口、练习播放器、学习中心、模拟面试、成长档案、设置。
- 移动端 390×844：登录、首页、练习播放器、学习中心、主题菜单、底部导航。
- 首页至少检查六套主题；其他页面检查 `daylight`、`aurora`、`constructivist`、`glass` 四种代表性材质。
- 检查横向溢出、遮挡主行动、焦点可见性、长中文换行和暗色对比度。
- 检查动态效果开启、产品开关关闭与系统减少动态效果三种状态。

## 非目标

- 不修改 Product API、Agent Runtime、Prisma、数据库或公共契约。
- 不重写推荐、练习、面试、报告、搜索或认证状态机。
- 不改 Admin Console。
- 不新增虚构指标、倒计时、总题数、后端状态或数据字段。
- 不追求逐像素复刻任何参考网站。

## 完成标准

1. 用户可以在六套主题之间切换，刷新后偏好保持，旧偏好可迁移。
2. 中文字体和中文界面文案在主要页面一致，滚动字幕全部中文。
3. 六套主题在颜色之外对字体、边框、圆角、阴影、材质和动效有明确差异。
4. 登录、首页、练习、学习、面试、成长与设置形成统一视觉系统。
5. 动效开启时连贯，关闭时完整可用，后台与低性能场景不会持续消耗资源。
6. 用户端测试、lint、类型检查和生产构建通过；浏览器视觉检查记录已验证与未验证边界。
