# PDF 书籍库

这个目录专门存放 PDF 书籍原件和按章提取的 Markdown，不和学习笔记、面试题混在一起。

## 为什么单独一个模块

- PDF 是二进制大文件，放在学习笔记/面试题目录里会打乱笔记结构，也不方便 Obsidian 搜索。
- 书籍需要保留原排版（图表、公式、代码），同时提供可检索的文本，所以拆成「原件 + 章节 Markdown」两层。
- 以后新增书籍只需要建一个子目录，复制 `README.md` 的结构，不污染其他目录。

## 目录约定

```text
PDF书籍/
└── <书名>/
    ├── README.md            # 元数据、目录、阅读建议
    ├── <书名>.pdf           # PDF 原件
    └── 章节/
        └── 第01章-xxx.md    # 按章提取的 Markdown
```

> 提取文本会丢失图片、复杂表格和公式排版；精确内容以 PDF 原件为准。
