## 各章一句话

1. **AI Agent 入门**：Agent = LLM + 上下文 + 工具；介绍 Harness、ReAct 循环与观察/动作空间。
2. **上下文工程**：消息结构、KV Cache、提示工程、Skills、Agent 状态栏和上下文压缩。
3. **用户记忆和知识库**：记忆分层、RAG 基础、混合检索、结构化知识组织和 Agentic RAG。
4. **工具**：工具分类与设计原则、MCP/Skill Hub、工具按需发现、感知/执行/协作工具。
5. **Coding Agent 与通用 Agent**：Coding 作为 Agent 基础能力、Harness 实践和错误恢复。
6. **交互**：Computer Use、GUI 观察与动作空间扩展、长程任务的能力断层。
7. **Agent 的评估**：评测体系、指标、实验设计和失败归因。
8. **模型后训练**：SFT、RL、GRPO、多轮 Agentic RL 和奖励设计。
9. **Agent 的持续进化**：数据飞轮、经验学习和能力迭代。
10. **多 Agent 协作**：协作架构、通信、角色分工与编排取舍。

## 怎么用

- 先读第 1 章建立概念地图，再按「上下文 → 记忆/知识库 → 工具 → Coding/交互 → 评测/后训练 → 多 Agent」顺序读。
- 每章末尾有「本章小结」和「思考题」，可以直接当面试自测题。
- 做笔记时在自己的 Markdown 里引用章节文件，不要直接改提取文本；重新提取会覆盖。
- 面试前重点看第 1、2、3、7、10 章，和当前两个项目（Interview Agent、Knowledge Hub）的考点最贴。
